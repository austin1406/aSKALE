# Askale

Website for Askale: websites and AI automations for local businesses in Richardson and Irving, TX.

This repo is also the first build of the agency's starter template. Every client site will start from the patterns proven here.

## Run it locally

```bash
npm install
cp .env.example .env.local   # fill in keys as features need them
npm run dev                  # http://localhost:3000
```

## Where things live

- `src/site.config.ts`: brand name, prices, contact details, booking link
- `src/app/globals.css`: brand colors
- `src/app/page.tsx`: home page sections
- `CLAUDE.md`: how Claude should work in this repo
